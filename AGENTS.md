# Project Rules & Guidelines

## Core Principles
1. **Think Before Coding**:
   - Understand the exact requirement thoroughly before typing any code.
   - Clarify edge cases and plan the simplest direct solution first.

2. **Keep It Simple**:
   - Avoid over-engineering, unnecessary abstractions, or overly complex designs when a clean, simple, and robust solution works best.
   - Do what is requested cleanly and directly.

3. **Surgical Changes (Touch Only What's Needed)**:
   - Edit only the specific lines or functions that are strictly required for the feature or fix.
   - Never rewrite entire files or alter working code/styles unnecessarily.

4. **Work Until Goal is Verified**:
   - Don't just make the edit and assume it works.
   - Test and verify thoroughly (syntax check, runtime verification, browser testing) until the goal is 100% verified and confirmed working.

## Project Scope & Communication
- **Scope**: Focus strictly and exclusively on **HISAB PRO** (`hisab-software`). No other projects are to be involved.
- **Language**: Always communicate with the user in **Gujarati**.
