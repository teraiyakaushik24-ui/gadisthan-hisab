**HISAB PRO** is a daily cash, bank deposit, voucher, and donation accounting software tailored for **Shree Gadisthan Jetpur**. ## Data Flow

1. **User Action:** Operator logs in and enters daily cash donations, bank deposits, or voucher disbursements.
2. **Gujarati Translation:** `gujaratiTyping.js` converts phonetic keystrokes to Gujarati text in real-time.
3. **API Submission:** Client sends transaction payload via `fetch()` to `server.js` with authentication token.
4. **Validation & Balance:** `server.js` validates denominations, computes closing balance, and logs audit record.
5. **Persistence:** `db.js` updates MongoDB Atlas collection and syncs to local JSON files in `data/`.
6. **Confirmation & Receipt:** Server returns receipt confirmation; client generates printable PDF via `html2pdf.bundle.min.js`.

## Technical Debt

- [ ] **Monolithic `server.js`:** The backend server file is over 6,000 lines. Refactor routes into dedicated modules (`routes/auth.js`, `routes/records.js`, `routes/admin.js`).
- [ ] **Monolithic Client `app.js`:** Client-side JavaScript contains extensive direct DOM manipulations and state handling in a single script.
- [ ] **Dual-Sync Concurrency:** Bi-directional sync between MongoDB Atlas and local JSON files needs explicit locking to avoid race conditions during concurrent edits.
