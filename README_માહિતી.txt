૨. સૌથી સરળ રસ્તો (૧-ક્લિક ઓટોમેટિક સેટઅપ):
----------------------------------------------------------------------
👉 ફાઇલનું નામ: Setup-And-Run-Hisab.bat

તમારે Windows 7 કે કોઈ પણ નવા કમ્પ્યુટરમાં ફક્ત આ ૧ જ ફાઇલ પર ડબલ ક્લિક
કરવાનું છે. 

આ ફાઇલ પોતાની મેળે નીચે મુજબના તમામ કામ ૧૫ જ સેકન્ડમાં કરી દેશે:
  ૧. GitHub પરથી લેટેસ્ટ કોડ ઓટોમેટિક ડાઉનલોડ કરશે.
  ૨. Windows 7 માટે આઇકન/ઇમોજી ફોન્ટ જાતે જ ઇન્સ્ટોલ કરી દેશે 
     (તમારે અલગથી ફોન્ટ ઇન્સ્ટોલ કરવાની જરૂર નથી).
  ૩. કમ્પ્યુટરના ડેસ્કટોપ પર "HISAB PRO" નો સરસ આઇકન બનાવી દેશે.
  ૪. અને સીધું Google Chrome માં સોફ્ટવેર ચાલુ કરી આપશે!


૩. રોજિંદો ઉપયોગ કેવી રીતે કરવો (DAILY USAGE):
----------------------------------------------------------------------
- એક વાર સોફ્ટવેર શરૂ થઈ જાય પછી સર્વર આખો દિવસ બેકગ્રાઉન્ડમાં ચાલુ રહે છે.
- તમે ગમે ત્યારે Chrome બ્રાઉઝરમાં "http://localhost:3000" ખોલશો એટલે 
  સીધું જ સોફ્ટવેર ખૂલી જશે.
- ટિપ: બ્રાઉઝરમાં આ લિંકનો Bookmark (Ctrl + D) બનાવી લેવો.


૪. ૦-ક્લિક ઓટોમેટિક સેટિંગ (AUTO-START ON PC BOOT):
----------------------------------------------------------------------
👉 ફાઇલનું નામ: Enable-AutoStart-On-Boot.bat

- જો તમારે દરરોજ કમ્પ્યુટર ચાલુ કરો ત્યારે આઇકન પર પણ ક્લિક ન કરવું હોય,
  તો આ ફાઇલ પર ફક્ત એક વાર ડબલ ક્લિક કરી દો.
- હવેથી જ્યારે પણ તમે કમ્પ્યુટર ચાલુ કરશો, ત્યારે Windows ખૂલતાંની સાથે 
  જ HISAB PRO આપમેળે બ્રાઉઝરમાં સામે ખૂલી જશે!
- જો આ સેટિંગ બંધ કરવું હોય, તો "Disable-AutoStart.bat" વાપરવી.


૫. વધારાની (બેકઅપ) ફાઇલોની સમજૂતી:
----------------------------------------------------------------------
- Start-Hisab-Pro-Silent.vbs:
  કાળી વિન્ડો વગર એકદમ સાયલન્ટલી ૨ સેકન્ડમાં સોફ્ટવેર ચાલુ કરવા માટે.

- Stop-Hisab-Pro.bat:
  જો ક્યારેય ચાલુ સર્વરને બંધ કરવું હોય તો આના પર ક્લિક કરવું.

- Install-Emoji-Font-Win7.bat:
  આ ફક્ત બેકઅપ માટે છે (Setup-And-Run-Hisab.bat ફોન્ટ જાતે જ ઇન્સ્ટોલ કરે છે, 
  પણ જો ક્યારેય અલગથી ફોન્ટ નાખવો હોય તો જ આ વાપરવી).

- Debug-Start.bat:
  જો ક્યારેય કોઈ ટેકનિકલ ખામી લાગે તો કન્સોલ વિગત જોવા માટે.
